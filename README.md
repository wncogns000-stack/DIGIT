# DIGIT 교실판

보드게임 **DIGIT(디지트)** 를 교실에서 팀 대항으로 진행할 때 쓰는 웹앱입니다.
카드는 선생님이 실물로 나눠 주고, 이 앱은 **막대 5개가 놓인 게임판**과 **팀 점수·차례 관리**를 맡습니다.

설치할 것은 없습니다. `index.html`을 크롬·엣지 같은 브라우저로 열면 바로 실행됩니다.
(인터넷이 없으면 글꼴만 컴퓨터 기본 글꼴로 바뀌고 기능은 그대로입니다.)

## 수업 흐름

1. **게임 설정**: 팀 수(2~6팀)를 고르고, 원하면 팀 이름을 적은 뒤 `게임 시작`.
2. 학생이 "빨간 막대를 저기로 옮겨 주세요"라고 요청하면 `전체화면`을 띄우고 막대를 옮깁니다.
   - 막대를 누른 뒤 옮길 자리를 누르거나, 끌어다 놓으면 됩니다.
   - 막대 색: 빨강 · 노랑 · 초록 · 파랑 · 보라
   - 잘못 옮겼으면 `되돌리기`.
3. 학생이 카드를 들고 와서 확인을 받으면 `성공 +1`.
   - 같은 팀이 이어서 하고, 연속 성공은 최대 5번까지입니다. 5번째 성공이면 차례 끝 화면이 자동으로 뜹니다.
4. 실패했거나 차례를 마칠 때는 `차례 넘기기`.
   - 차례 끝 화면에 **이번 차례에 성공한 만큼 보충할 카드 장수**가 나옵니다. 그만큼 카드를 나눠 주면 다시 5장이 됩니다.
   - 다음 팀으로 넘어가고, 마지막 팀 다음에는 1팀부터 새 라운드가 시작됩니다.

## 기능

- 팀 2~6팀, 팀 이름 지정(비우면 "1팀", "2팀"…)
- 막대 5개를 서로 다른 색으로 표시, 격자에 맞춰 놓기
- 전체화면 모드: 판을 크게 띄우고 위쪽 한 줄에 `성공 +1`, `차례 넘기기`, `되돌리기`만 남김
- 점수판: 지금 차례인 팀 강조, 선두 표시, 팀별 `+` / `−` 로 점수 직접 수정
- 가운데로 모으기: 막대들이 가장자리로 몰렸을 때 모양은 그대로 둔 채 5개를 한꺼번에 판 가운데로 옮김
- 되돌리기: 막대 이동, 성공, 차례 넘김, 점수 수정을 시간 순서대로 하나씩 취소
- 메뉴
  - `지금 모양을 시작 모양으로 저장`: 원하는 시작 배치를 저장해 다음 게임에도 사용
  - `막대를 시작 모양으로 되돌리기`
  - `점수 순위 보기`, `새 게임 설정`
- `막대에 색 이름` 버튼: 막대 위에 "빨강", "노랑" 같은 글자를 표시 (색을 구분하기 어려운 학생용)
- 진행 상황은 브라우저에 자동 저장됩니다. 새로고침해도 설정 화면의 `이어서 하기`로 돌아올 수 있습니다.

## 키보드 단축키

| 키 | 동작 |
| --- | --- |
| `1`~`5` | 빨강·노랑·초록·파랑·보라 막대 고르기 |
| 방향키 | 고른 막대를 한 칸 이동 |
| `R` | 고른 막대를 세우기/눕히기 |
| `C` | 막대 5개를 모양 그대로 가운데로 모으기 |
| `S` | 성공 +1 |
| `N` | 차례 넘기기 |
| `Z` 또는 `Ctrl+Z` | 되돌리기 |
| `F` | 전체화면 켜기/끄기 |
| `Esc` | 막대 선택 취소 |

한글 입력 상태에서도 단축키가 동작합니다.

## 참고

- 기본 시작 모양은 디지털 숫자 "2" 모양입니다. 실제 게임에서 쓰는 시작 모양이 다르면 막대를 배치한 뒤 메뉴의 `지금 모양을 시작 모양으로 저장`을 누르세요.
- 앱은 막대 배치가 카드와 맞는지 판정하지 않습니다. 성공 여부는 선생님이 카드를 보고 판단합니다.
- 저장 데이터는 사용하는 브라우저 안에만 남습니다. 다른 컴퓨터나 다른 브라우저에서는 이어지지 않습니다.
